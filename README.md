# AirCargo Manager Pro

نظام ويب متكامل لإدارة عمليات الشحن الجوي، يبدأ من الحجز والتسعير ويمتد إلى التتبع وإصدار e-AWB وإدارة الرحلات والعملاء والفواتير والتقارير.

> **نسخة العرض الحالية تعمل بالكامل داخل المتصفح** وتستخدم `localStorage` للتخزين المحلي. وهي مناسبة للتجربة والعروض الأولية، وليست بديلاً عن نظام إنتاج متعدد المستخدمين قبل إضافة خادم وقاعدة بيانات وصلاحيات وصول.

## المزايا

| الوحدة | ما تقدمه |
|---|---|
| لوحة التحكم | مؤشرات الحجوزات والشحنات والرحلات والسعة والإيرادات والمبالغ المستحقة |
| الحجوزات | إنشاء الحجوزات، حساب الوزن الحجمي، التسعير، وربط العميل والوكيل والرحلة |
| التتبع | خط زمني من 12 مرحلة لكل شحنة مع رقم AWB أو رقم الحجز |
| e-AWB | إنشاء سجل بوليصة وتنزيل نسخة PDF قابلة للطباعة |
| الرحلات والسعات | إدارة الرحلات وقياس السعة المستخدمة مع تنبيهات مرئية للاكتظاظ |
| العملاء والوكلاء | حفظ بيانات الأطراف وحساب العمولات التقديرية |
| التقارير | تقارير الحجوزات والإيرادات والشحنات، مع تصدير Excel وطباعة |
| النسخ الاحتياطي | تصدير واستيراد قاعدة البيانات بصيغة JSON |
| التدقيق | سجل زمني للعمليات الرئيسية داخل النظام |

## التشغيل المحلي

لا يحتاج المشروع إلى تثبيت حزم. افتح `index.html` مباشرة في متصفح حديث، أو شغّل خادماً محلياً بسيطاً:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

اضغط **تحميل بيانات تجريبية** لاستكشاف النظام، ويمكن استخدام أزرار التصدير والاستيراد لحفظ نسخة من البيانات المحلية.

## التقنية

HTML5، وTailwind CSS عبر CDN، وJavaScript Vanilla، وChart.js، وjsPDF، وSheetJS، وواجهة `localStorage`.

## تحسينات هذه النسخة

أضيف دعم قائمة جانبية أفضل على الشاشات الصغيرة، ومنع تعارض المعرفات عند الإنشاء السريع، ومعالجة أكثر أماناً للبيانات المحلية التالفة، والتحقق من بنية ملفات الاستيراد، ومنع تكرار رقم AWB أو إصدار أكثر من AWB للحجز نفسه، إضافة إلى التخلص من نسخ Chart.js القديمة عند إعادة الرسم.

## خارطة الطريق المقترحة

الخطوة التالية للإنتاج هي نقل التخزين من `localStorage` إلى API وقاعدة بيانات، وإضافة تسجيل دخول وصلاحيات حسب الدور، وواجهة دفع وفوترة رسمية، وتكاملات شركات الطيران أو Cargo-XML، وسجل تدقيق غير قابل للحذف، واختبارات آلية شاملة.

## الترخيص
